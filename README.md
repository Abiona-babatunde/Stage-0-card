# Stage-0-card
Stage 0 Frontend Profile Card Task

This project is a responsive and accessible Profile Card built using semantic HTML, modern CSS, and vanilla JavaScript for the Frontend Wizards — Stage 0 Task.
It includes all required data-testid attributes for automated testing and follows accessibility and responsiveness standards.

index.html   →  Main markup (semantic HTML structure)
style.css    →  Styling and responsive design (includes media queries)
script.js    →  Handles real-time milliseconds display using Date.now()

All automated tests can target elements using these data-testid attributes:

test-profile-card

test-user-name

test-user-bio

test-user-time

test-user-avatar

test-user-social-links

test-user-hobbies

test-user-dislikes

Media queries are included for multiple screen sizes:

Device Type	Width Range	Layout Behavior
Mobile	up to 600px	Stacked layout, centered content
Tablet	601px–900px	Balanced layout with adjusted spacing
Desktop	901px+	Wider layout with side-by-side elements
